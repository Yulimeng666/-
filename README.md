# 电商购物平台后端系统
## 项目介绍
本项目为Java后端实训电商B2C购物平台，基于SpringBoot快速开发，实现普通用户在线选购商品、加入购物车、提交订单、库存扣减全流程业务，完整覆盖电商基础核心业务场景。
适合Java后端入门学习，包含数据库设计、事务控制、并发超卖处理、Redis缓存落地、RESTful接口规范等核心知识点。

## 技术栈
### 后端核心框架
- Java 8
- SpringBoot 2.x
- Spring、SpringMVC、MyBatis
- Maven 项目构建工具
### 数据存储 & 缓存
- MySQL 8.0（InnoDB引擎，事务、行锁）
- Redis 5.x（缓存购物车、热点商品数据）
### 开发&测试工具
- Postman 接口自动化测试
- Navicat 数据库可视化管理
- IDEA 开发工具

## 功能模块
1. 用户模块：用户基础信息管理、登录校验
2. 商品模块：商品分类、商品信息CRUD、多条件筛选查询
3. 购物车模块：商品添加、修改数量、选中/取消、批量结算（Redis缓存实现）
4. 订单模块：创建订单、订单明细生成、状态管理
5. 库存模块：并发库存扣减，防超卖处理
6. 公共模块：全局统一返回封装、全局异常处理、参数校验

## 项目亮点（核心技术落地）
1. 数据库设计：自主设计8张核心业务数据表，合理规划一对多关联关系，建立业务索引优化查询效率，不使用物理外键提升并发性能；
2. 事务保障：使用Spring声明式事务`@Transactional`保证下单流程「创建订单+扣减库存」原子性，避免数据不一致；
3. 并发超卖解决方案：通过`update ... where stock > 0`行锁SQL + Redis库存缓存削峰，双重机制解决并发下单超卖问题；
4. Redis缓存优化：购物车采用Hash数据结构缓存，读写性能大幅提升，分离冷热数据，减轻MySQL查询压力；
5. 标准化开发：遵循RESTful API设计规范，统一接口返回格式，全局异常切面统一捕获处理，代码低耦合易维护；
6. 团队协作适配：接口分层清晰（Controller/Service/Mapper），支持前端快速对接联调，配套Postman接口测试用例。

## 环境部署启动步骤
1. 环境准备
   - 本地启动MySQL，执行项目根目录sql文件夹下`shop.sql`初始化数据库表结构与测试数据；
   - 本地启动Redis服务，默认6379端口；
2. 配置文件修改
   修改`application.yml`配置文件，替换本地MySQL账号密码、Redis连接地址；
3. Maven打包/运行
   - IDEA直接运行启动类 `ShopApplication`；
   - 打包命令：`mvn clean package`，jar包通过`java -jar xxx.jar`部署启动；
4. 接口测试
   导入项目内Postman接口json文件，即可直接调用所有后端接口测试。

## 数据库表清单
用户表、商品分类表、商品表、库存表、购物车表、订单主表、订单明细表、角色权限表（共8张核心业务表）

## 学习总结
通过本项目完整掌握SpringBoot整合MyBatis、Redis整套后端开发流程；深入理解MySQL事务、行锁、索引、并发超卖等实际业务痛点解决方案；熟练运用Redis实现缓存业务，具备独立开发中小型管理/电商后端项目的能力。
